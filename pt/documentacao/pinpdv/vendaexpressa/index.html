Venda Expressa

Nesta página
  • Endpoints
  • Consultando vendas
  • Exemplo de resposta

Transações iniciadas diretamente no Smart POS pelo operador, sem envolvimento do sistema no momento da venda. Com este módulo, seu sistema captura dados de pagamentos que ele mesmo não originou — tudo o que foi cobrado no Smart POS fica disponível para consulta.

É o caminho ideal para:

  • Conciliação de cartões — cruzar o que foi capturado no terminal com os recebíveis do adquirente
  • Validações gerenciais — auditar vendas, conferir totais por Smart POS e acompanhar a operação
  • Vinculação de pagamentos — associar transações avulsas a pedidos, comandas ou documentos fiscais no seu sistema

Impressão de documentos

A Venda Expressa não suporta impressão via sistema (webhook ou PUT /comprovante) — o operador digita o valor direto no Smart POS, sem janela para o sistema injetar o documento. Para impressão gerenciada pelo sistema, use o TEF Mobile, a Pré-venda ou a Venda Avulsa — veja Impressão.

Sem criação via API

Não existe endpoint para criar uma Venda Expressa. Ela é iniciada exclusivamente pelo operador no Smart POS — seu sistema apenas consulta as vendas realizadas.

Endpoints#

MétodoEndpointDescrição
GET/venda?FiltroTipoVenda=ExpressaConsultar vendas expressas

Consultando vendas#

Filtros disponíveis:

ParâmetroValoresDescrição
FiltroTipoVendaExpressaObrigatório para este módulo
DataInicialYYYY-MM-DDTHH:MM:SSInício do período
DataFinalYYYY-MM-DDTHH:MM:SSFim do período
FiltroStatusRealizada, Cancelada, ErrorStatus da venda
FiltroTipoPagamentoCredito, Debito, Pix, CrediarioMeio de pagamento
FiltroPinPdvCódigo do dispositivoSmart POS específico
PaginaNumeroInteiroPágina (padrão: 1)
QtdRegistroInteiroRegistros por página (padrão: 100)
OrdenarPorId, Valor, Status, CadastradoEm, AtualizadoEmCampo de ordenação
OrdenarTipoASC, DESCDireção da ordenação

Os valores de status de venda, status de pagamento e tipos de pagamento estão em Referência.
