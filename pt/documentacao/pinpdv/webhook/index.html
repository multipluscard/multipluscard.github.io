Webhook

Nesta página
  • Como cadastrar a URL do webhook
  • Acompanhando as notificações
  • Valor enviado pelo PINPDV

O webhook é o canal de notificações de venda do PINPDV. Em vez de o seu sistema ficar consultando o status (polling), é o PINPDV que avisa o seu sistema sempre que algo muda em uma venda.

A cada alteração em uma venda — criação, atualização de status e conclusão — o PINPDV envia um POST para a URL que você cadastrou. Vale para todos os módulos que geram vendas: TEF Mobile, Pré-venda, Venda Expressa e Venda Avulsa.

Só é enviado se houver URL cadastrada

O webhook só é ativado quando existe um endereço cadastrado. Sem URL, nenhuma notificação é enviada — e o acompanhamento da venda passa a depender de polling.

Cadastre a URL no Portal do Cliente PINPDV, em Configurações → Configuração → Webhook.

Como cadastrar a URL do webhook#

O cadastro é feito no Portal do Cliente PINPDV, em três passos. Clique nas imagens para abri-las em tamanho real.

1. Abra o menu do usuário. No canto superior direito do portal, clique sobre o nome do usuário logado.

2. Selecione “Configurações”. No menu que se abre, clique em Configurações.

3. Informe a URL em “Webhook”. Na aba Configurações do Portal → Configuração, o primeiro bloco da página é o Webhook. Preencha o campo com o endereço que vai receber as notificações (protocolo https://) e salve.

A partir do salvamento, toda alteração de venda passa a ser notificada nessa URL. Para desativar o webhook, basta apagar o endereço e salvar.

Acompanhando as notificações#

Os envios podem ser acompanhados no Portal do Cliente PINPDV, em Configurações → Inspeção Técnica → Notificações de Venda. Use essa tela para auditar o que foi disparado e diagnosticar falhas de entrega.

Valor enviado pelo PINPDV#

A cada alteração na venda, o PINPDV envia um POST para a sua URL com o corpo em JSON. Use o campo status para identificar o momento relevante para o seu fluxo (ex.: agir apenas quando status.value = "Realizada").

Os valores de status, tipoVenda e pagamentoTipo estão em Referência.
